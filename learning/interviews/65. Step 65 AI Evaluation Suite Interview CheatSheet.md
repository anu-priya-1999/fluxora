# 65. Step 65 AI Evaluation Suite Interview CheatSheet

## 30-Second Pitch

> "In Step 65, we built Fluxora's continuous AI evaluation suite. Because our output validator only proves an `evidence_id` is in the allowed manifest—not that it actually supports the claim—we added a semantic groundedness evaluator, a deterministic named-entity hallucination checker, a clean-vs-adversarial prompt-injection fixture, and release gates separating offline CI mock verification from budget-bounded live model baselines."

## Key Talking Points

1. **Three Levels of Grounding**: Structural association (context assembly) != manifest membership (output validator) != semantic support (eval suite).
2. **Hallucination Math**: `(unsupported + contradicted) / totalEvaluatedClaims`. Ambiguous claims are never silently counted as supported.
3. **Why `inconclusive` Matters**: A `<2%` hallucination gate on 5 mock cases is not a real Claude baseline—our gate explicitly returns `inconclusive` for mock runs or undersized samples (`<20` claims).
4. **Prompt Injection Testing**: Clean vs. adversarial Taxonomy fixtures share identical deterministic facts while injecting overrides in README, comments, XML tags, and chat questions—verifying deterministic invariance, unicode XML escaping, manifest rejection, and tool allowlist enforcement.
5. **Cost & Retry Discipline**: 100% schema validity within the 2-attempt ceiling; rising retry rates block promotion; mock runs report `null` cost rather than fabricating `$0`.

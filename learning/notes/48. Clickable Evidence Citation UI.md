# 48. Clickable Evidence Citation UI

## Overview & System Role

Global Step 49 implements **Clickable Evidence Citation UI** under **Phase 7: Evidence Engine** of the Fluxora Engineering Roadmap (`docs/architecture/17-implementation-roadmap.md`, Phase 7, Step 2).

In Fluxora, evidence is not a decorative metadata tooltip; it is the **provenance spine** of the digital twin. When Fluxora asserts that an API route is affected by a pull request, or that two microservices share a database table, or that an interface is extended across modules, an engineer must be able to audit that claim directly at the exact line of code where the relationship was discovered.

Global Step 49 transforms backend evidence into an interactive, clickable `EvidenceCitation` component in the frontend, providing seamless traceability from high-level graph conclusions to exact source coordinates while strictly preventing URL fabrication or synthetic line ranges.

## 1. Traceability Flow

```
┌────────────────────────────────────────────────────────┐
│                      Conclusion                        │
│   (Graph Edge / PR Impact Finding / Node Provenance)   │
└───────────────────────────┬────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│                   EvidenceCitation                     │
│  - Compact chip: filename, line badge, confidence %    │
│  - Expanded card: relationship, symbol, analysis run   │
└───────────────────────────┬────────────────────────────┘
                            │ Click
                            ▼
┌────────────────────────────────────────────────────────┐
│                 GitHub Source Permalink                │
│  https://github.com/{repo}/blob/{sha}/{file}#L{lines}  │
│                                                        │
│  OR: Honest "Source link unavailable" with explanation │
└────────────────────────────────────────────────────────┘
```

## 2. Key Engineering Pillars

### A. Non-Fabrication of Provenance
- Source permalinks require valid repository coordinates (`owner/repo`), a resolved commit SHA or branch ref, and a verified relative file path.
- Line range anchors (`#L10–L25` or `#L10`) are generated **only** when AST or compiler analysis extracted genuine 1-based line numbers.
- If a commit is unresolved or a file path cannot be securely validated, the system displays "Source link unavailable" with an honest reason tooltip (`title="Commit reference is not resolved"`).
- We never invent placeholder values like `L0`, `HEAD`, or `main`.

### B. Security & Path Traversal Sanitization
- File paths from untrusted evidence metadata are sanitized before constructing external URLs.
- Traversal attempts (`../`, `..\\`), absolute paths (`/etc/passwd`), protocol schemes (`javascript:`, `data:`), and illegal URI characters are rejected.
- Permalinks are rendered as secure external links: `target="_blank"`, `rel="noopener noreferrer"`.

### C. React 19 Prop Discipline (`gitRef` vs `ref`)
- In React 19, `ref` is a reserved component keyword. Modern ESLint rules (`react-hooks/refs`) disallow accessing or passing props named `ref` during render.
- Renaming the domain prop to `gitRef` (while supporting backwards-compatible aliases) prevents linting and compiler errors while preserving clean semantic separation.

### D. Multi-Tenant Backend Integration
- `GET /api/v1/impact-analyses/:id` was extended to return formatted evidence records (`GraphQueryResponseEvidence[]`) joined using `listImpactFindingEvidence`.
- RLS policies guarantee tenant isolation: an organization can only read evidence belonging to its own runs.

---

## 3. UI Integration Surfaces

1. **Edge Inspector**: Selecting any graph edge displays its type, relationship description, confidence, and an expanded `EvidenceCitation` linked to the edge's `evidence_id`.
2. **Node Inspector Panel & EvidenceTrail**: Displays verified source code provenance linking the selected graph node to exact source files with clickable GitHub permalinks.
3. **PR Change Mode**:
   - The `ChangeModeBar` includes an expandable `impact-findings-panel` listing all direct, downstream, API, and event impact findings with inline `EvidenceCitationList` components.
   - Nodes in the graph can be clicked to highlight the finding and view its provenance.

# 25. Full Phase 3 Golden Pipeline Verification

## Concept Overview

Phase 3 of Fluxora transforms an unparsed repository snapshot into extracted symbols, module relationships, API route entrypoints, event producer/consumer patterns, database interaction points, and canonical normalized entities.

Global Step 26 is the final verification milestone of Phase 3. It constructs a pure, deterministic, multi-stage static analysis orchestrator (`runPhase3Pipeline`) and validates the entire Phase 3 stack end-to-end against the production golden fixture repository (`shadcn-ui/taxonomy`).

---

## The 8 Processing Stages

1. **Step 18 — Stack Detection**: Inspects file extensions, manifests (`package.json`), and config files (`tsconfig.json`, `next.config.mjs`) to identify supported languages (TypeScript, JavaScript, JSON, CSS, Markdown) and frameworks (Next.js, React, Node.js).
2. **Step 19 — Per-File AST Symbol Extraction**: Uses TypeScript Compiler API AST traversal to extract functions, classes, interfaces, types, and constants/variables with source locations and export metadata.
3. **Step 20 — Import/Export Module Graph**: Parses static import/export statements and resolves relative paths and `tsconfig.json` path aliases (`@/*`).
4. **Step 21 — API Route & Express Router Detection**: Detects Next.js App Router HTTP handlers (`GET`, `POST`, `PATCH`, `DELETE`) and Express router mounts.
5. **Step 22 — Event Pattern Detection**: Detects EventEmitter, Redis, KafkaJS, and RabbitMQ pub/sub method shapes.
6. **Step 23 — Database Reference Detection**: Detects ORM/database interactions (Prisma, Drizzle, TypeORM, Sequelize).
7. **Step 24 — Tree-sitter Fallback Pass**: Executes WebAssembly Tree-sitter parsing for non-TS/JS files (JSON, CSS, HTML, Markdown) to ensure multi-language coverage.
8. **Step 25 — Normalization**: Dedupes symbols, resolves barrel file re-export chains, assigns canonical IDs (`sym:...`, `edge:...`, `route:...`), and produces statistics.

## Key Design Invariants

- **Determinism**: Zero random UUIDs, zero timestamps, zero process-state dependencies.
- **Zero Persistence**: No database tables or graph storage created in Phase 3.
- **Zero AI Dependency**: Non-LLM static analysis core.
- **Safety**: Un-sandboxed customer code is never executed.
